প্রজেক্টের লোকেশন ম্যাপ — সম্পূর্ণ গাইড

Shopno Bilash Properties · Admin ও Developer-এর জন্য · ফিচারটি ইতিমধ্যে ওয়েবসাইটে যোগ করা আছে

১. এটা কী এবং কী পরিবর্তন হয়েছে

আগে প্রজেক্ট পেজের "Location" অংশে শুধু একটি ফাঁকা বক্স (পিন আইকন ও এলাকার নাম) দেখা যেত। এখন Admin Panel থেকে প্রতিটি প্রজেক্টে একটি Google Maps link দেওয়া যায়। লিংক দিলে ওই বক্সের জায়গায় আসল লাইভ ম্যাপ আসে, আর তার নিচে "Open in Google Maps" বাটন থাকে, যাতে ক্লায়েন্ট সরাসরি ফোনের Maps অ্যাপে রাস্তা (directions) দেখতে পারে।

  • কোনো খরচ নেই, কোনো API key লাগে না। Google-এর সাধারণ embed ব্যবহার হয়; আমাদের server-এ কিছু আপলোড বা জমা হয় না, শুধু পেস্ট করা লিংকটুকু প্রজেক্টের সাথে সেভ হয়।
  • লিংক না দিলে আগের মতো সাধারণ বক্স (placeholder) দেখাবে। কোনো ভুয়া ম্যাপ বা ভুয়া দূরত্ব দেখানো হয় না।
  • নতুন কোনো database migration লাগেনি, তাই deploy করলেই কাজ করে।

২. ম্যাপ যোগ করার ধাপ (Admin)

ধাপ ১ — Google Maps থেকে লিংক নিন

  1. ফোনে বা কম্পিউটারে Google Maps খুলুন।
  2. সার্চ বক্সে প্রজেক্টের জায়গা খুঁজুন। যদি ঠিক জায়গাটি না আসে, ম্যাপে আঙুল দিয়ে বা ক্লিক করে ঠিক বিল্ডিংয়ের জায়গায় পিন (Drop pin) বসান।
  3. Share চাপুন। এখানে তিনটি উপায় আছে (নিচের টেবিলে কোনটা সবচেয়ে ভালো দেখুন):
উপায়কীভাবেফল
A. Embed code (সবচেয়ে ভালো)Share → Embed a map ট্যাব → COPY HTML। (এই অপশন কম্পিউটারের Google Maps-এ পাওয়া যায়।)পেজে লাইভ ম্যাপ + Open বাটন
B. সাধারণ লিংকব্রাউজারের address bar থেকে পুরো লিংক কপি করুন (যেমন https://www.google.com/maps/place/…/@23.79,90.40,15z)।লাইভ ম্যাপ + Open বাটন
C. Coordinatesম্যাপে পিনের ওপর রাইট-ক্লিক করলে উপরে সংখ্যা দেখা যায়, সেটি কপি করুন, যেমন 23.7925, 90.4078লাইভ ম্যাপ + Open বাটন
D. ছোট Share লিংকফোনে Share করলে যে https://maps.app.goo.gl/… লিংক আসে।পেজের ভেতরে ম্যাপ দেখা যায় না (Google অনুমতি দেয় না), শুধু Open in Google Maps বাটন আসে
পরামর্শ: সবচেয়ে ঠিকঠাক ফল চাইলে কম্পিউটারে A (Embed code) ব্যবহার করুন। ফোন থেকে করলে B বা C নিন; D শুধু তখনই, যখন আর কিছু পাওয়া যাচ্ছে না।

ধাপ ২ — Admin Panel-এ পেস্ট করুন

  1. Admin → Website → Projects খুলুন।
  2. নতুন প্রজেক্ট বানানোর সময় অথবা বিদ্যমান প্রজেক্টের Edit-এ যান।
  3. "Location Description"-এর ঠিক নিচে "Google Maps link (optional)" বক্সে কপি করা লিংক/কোড পেস্ট করুন।
  4. Save চাপুন।

ধাপ ৩ — পাবলিক পেজে যাচাই করুন

  1. ওয়েবসাইটে ওই প্রজেক্টের পেজ খুলে নিচে স্ক্রল করে Location অংশে যান।
  2. ম্যাপটি ঠিক জায়গায় পিন দেখাচ্ছে কি না দেখুন, এবং Open in Google Maps চেপে দেখুন সঠিক জায়গা খোলে কি না।
  3. ভুল জায়গা দেখালে Google Maps-এ পিনটি সরিয়ে আবার লিংক নিন ও পেস্ট করুন।

৩. ম্যাপ সরানো বা বদলানো

  • বদলাতে: Edit-এ গিয়ে বক্সে নতুন লিংক পেস্ট করে Save করুন।
  • সরাতে: বক্সটি পুরো খালি করে Save করুন। পেজে আগের সাধারণ বক্স ফিরে আসবে।

৪. কোন ধরনের লিংক গ্রহণযোগ্য, আর কেন ভুল আসতে পারে

নিরাপত্তার জন্য শুধু Google Maps-এর লিংক গ্রহণ করা হয়। অন্য কোনো ওয়েবসাইটের লিংক, http:// (https ছাড়া) লিংক বা কোড-জাতীয় কিছু পেস্ট করলে Save-এর সময় লাল বার্তা আসবে এবং কিছু সেভ হবে না।

সমস্যাকারণ ও সমাধান
Save-এ "That map link isn't one we can use" দেখাচ্ছেলিংকটি Google Maps-এর নয়, অথবা অসম্পূর্ণ কপি হয়েছে। আবার Share থেকে কপি করুন। Coordinates হলে দুই সংখ্যার মাঝে কমা দিন (যেমন 23.7925, 90.4078)।
শুধু বাটন আসছে, ম্যাপ আসছে নাছোট maps.app.goo.gl লিংক দিলে এমন হয়। পদ্ধতি A, B বা C দিয়ে আবার চেষ্টা করুন।
ম্যাপ ভুল জায়গা দেখাচ্ছেপিনটি ঠিক জায়গায় ছিল না। Google Maps-এ পিন ঠিক করে নতুন লিংক নিন।
ম্যাপের জায়গায় এখনো সাধারণ বক্সবক্সটি খালি আছে, অথবা Save হয়নি। সম্ভব হলে পেজ রিফ্রেশ করে দেখুন।
মনে রাখুন: ওয়েবসাইট এখনো beta। কিছু ঠিকঠাক না চললে বা ভুল দেখালে সমস্যাটি Developer-কে জানান।

ভবিষ্যতে যেমন বাড়াবেন

(ক) আরেকটি রেকর্ডে ম্যাপ চাইলে (যেমন Unit, Landowner সাইট):

  1. ওই রেকর্ডের টাইপে mapUrl?: string যোগ করুন (যেমন projects.ts-এ করা হয়েছে)।
  2. তার Admin ফর্মে ঠিক একই Input name="mapUrl" বসান।
  3. তার save action-এ checkMapField(String(formData.get("mapUrl") ?? "")) কল করে map.value সেভ করুন; error থাকলে ফেরত দিন।
  4. পাবলিক পেজে <LocationMap mapUrl={record.mapUrl} label={…} /> বসান। আর কিছু লাগবে না।

(খ) নতুন ধরনের লিংক সাপোর্ট করতে (যেমন Apple Maps, OpenStreetMap): শুধু parseMapInput()-এ একটি নতুন শাখা যোগ করুন, যা { embedUrl, openUrl } ফেরত দেয়। বাকি সব (ফর্ম, সেভ, পেজ) অপরিবর্তিত থাকে। iframe-এ নতুন হোস্ট যোগ করার আগে নিরাপত্তা হিসাব করুন: শুধু বিশ্বস্ত হোস্টের embed URL ফেরত দিন।

(গ) একই পেজে একাধিক ম্যাপ বা Nearby places-এর পিন: এখন একটি ম্যাপ। একাধিক হলে mapUrl-কে তালিকা (mapUrls: string[]) বানিয়ে LocationMap-কে লুপে ব্যবহার করুন।

(ঘ) নিজস্ব স্টাইলের ইন্টারঅ্যাক্টিভ ম্যাপ (পিন, রঙ, একাধিক মার্কার): তখন Google Maps JavaScript API বা Mapbox/Leaflet লাগবে; এতে API key ও কিছু ক্ষেত্রে বিলিং আসে। সেক্ষেত্রে LocationMap কম্পোনেন্টের ভেতরটা বদলান; ফর্ম ও ডেটা মডেলে latitude/longitude আলাদা ফিল্ড হিসাবে যোগ করা সুবিধাজনক।

নিরাপত্তা ও সীমাবদ্ধতা

  • কোনো কাঁচা HTML সেভ বা রেন্ডার হয় না। iframe কোড পেস্ট করলে শুধু তার src URL রাখা হয়, এবং সেটি Google-এর embed হলেই গ্রহণ করা হয়।
  • javascript:, data:, http: এবং অন্য ডোমেইন বাতিল হয়।
  • সাইটে Content-Security-Policy এখনো নেই (দেখুন next.config.ts)। ভবিষ্যতে CSP যোগ করলে frame-src-এ https://www.google.com ও https://maps.google.com অনুমতি দিতে হবে, নইলে ম্যাপ ফাঁকা হয়ে যাবে।
  • Embed code-এর ক্ষেত্রে "Open in Google Maps" বাটন embed লিংক থেকে বানানো হয়; কিছু ক্ষেত্রে সরাসরি সার্চ-পিনের মতো না-ও খুলতে পারে। সবচেয়ে নির্ভুল Open বাটন চাইলে পদ্ধতি B বা C ব্যবহার করুন।
  • এই ফিচারটি লোকাল ডেভ সার্ভারে পরীক্ষা করা হয়েছে (লিংক-পার্সার সহ); লাইভ সাইটে ম্যাপের iframe লোড হওয়া ডিপ্লয়ের পর আরেকবার দেখে নিন।

৬. এক নজরে (চেকলিস্ট)

  1. Google Maps-এ ঠিক জায়গায় পিন → Share → Embed a map → COPY HTML (বা সাধারণ লিংক/coordinates)।
  2. Admin → Website → Projects → Edit → "Google Maps link" বক্সে পেস্ট → Save।
  3. পাবলিক পেজে Location অংশে ম্যাপ ও Open বাটন যাচাই।
  4. সরাতে চাইলে বক্স খালি করে Save।
